# WasteWise - Experiments & Benchmarking

This directory contains research notebooks, prototyping scripts, and benchmark evaluation logs for experimental models.

## Structure (Future Phases)

* `notebooks/`: Jupyter/Colab notebooks for exploratory data analysis (EDA) and experimental model architectures.
* `benchmarks/`: Evaluation metrics (mAP, F1-score, latency, memory footprint) across candidate models.
* `configs/`: Hyperparameter settings and training configurations (e.g., Hydra, YAML).

> **Note**: Experimental runs and artifact outputs will be tracked systematically without polluting the core production services.
