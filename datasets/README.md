# WasteWise - Datasets

This directory manages dataset documentation, schemas, and acquisition scripts.

## Planned Datasets (Future Phases)

* **Satellite Imagery**: Sentinel-2 (European Space Agency), Landsat, Planet Labs high-resolution optical imagery.
* **Drone / UAV Orthomosaics**: High-resolution municipal aerial survey benchmarks.
* **Ground-level Annotations**: Open-source municipal waste benchmarks (e.g., TACO dataset, ZeroWaste dataset, municipal street images).
* **GIS Spatial Layers**: Municipal ward boundaries, road networks, landfill/transfer station locations.

> **Note**: Raw binary datasets and heavy raster files should never be committed to Git. Store metadata, URLs, and retrieval scripts in this directory.
